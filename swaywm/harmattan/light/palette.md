Harmattan has no external source palette (unlike Zephyr, which tracks Breeze) —
every value here was hand-picked for this scheme. See
`../README.md` for the design rationale. The seven accent hues (indigo, red,
green, yellow/orange, purple, cyan, plus their five "bright" companions) are
identical across Light/Dusk/Dark on purpose, so state colors — swaylock's
ring, mako's urgency border, a git diff's red/green — read the same
regardless of which variant is active. Only the neutrals (backgrounds,
foreground text, borders) and `link` (needs different weight for light-bg vs
dark-bg contrast) shift per variant.

Desktop wallpaper (`~/.img/wallpapers/harmattan_light_desktop.png`, soft
overlapping translucent circles in the 7 accent hues) and swaylock background
(`harmattan_light_lockscreen.png`, a subtle radial glow, bg → bg-panel-alt)
are both generated by `~/dotfiles/bin/palette_wallpaper.py --palette
harmattan_light` (desktop used `--pattern circles`; the lockscreen glow was
hand-tuned with extra noise dithering to avoid gradient banding — the
generator script used lives only in the session scratchpad, not in git
history, so it would need to be rewritten if regeneration is ever needed).
