Same hand-picked palette as Light and Dusk, inverted: near-black warm
neutrals instead of warm ivory, `link` bumped to the lightest of its three
weights for AA-adjacent contrast against the near-black background. Accent
hues are unchanged from Light/Dusk — same reasoning as Zephyr: state colors
(swaylock ring, mako urgency border, a diff's red/green) should read the
same no matter which variant is active. See `../README.md` for the overall
design rationale.

Desktop wallpaper (`~/.img/wallpapers/harmattan_dark_desktop.png`, soft
overlapping translucent circles in the 7 accent hues, alpha boosted for
visibility against the near-black base) and swaylock background
(`harmattan_dark_lockscreen.png`, a subtle radial glow, bg-panel →
bg-panel-alt) are both generated by `~/dotfiles/bin/palette_wallpaper.py
--palette harmattan_dark` (desktop pattern used `--pattern circles`; the
lockscreen glow was hand-tuned with extra noise dithering to avoid gradient
banding — the generator script used lives only in the session scratchpad,
not in git history).
