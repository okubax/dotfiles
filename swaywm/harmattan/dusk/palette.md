Like Zephyr Dusk, this variant has no source of truth other than itself —
neutrals are hand-picked as a warm, dim mid-tone (leaning dark, same logic
as Zephyr Dusk: "dusk" reads as early-night dimness, not a neutral halfway
gray) for working comfortably in low light without Harmattan Dark's full
contrast jump. Accent hues are unchanged from Light/Dark; only `link` gets
a lighter weight for legibility against the dark background. See
`../README.md` for the overall design rationale.

Desktop wallpaper (`~/.img/wallpapers/harmattan_dusk_desktop.png`, soft
overlapping translucent circles in the 7 accent hues) and swaylock
background (`harmattan_dusk_lockscreen.png`, a subtle radial glow, bg →
bg-panel-alt) are both generated by `~/dotfiles/bin/palette_wallpaper.py
--palette harmattan_dusk` (desktop used `--pattern circles`, alpha boosted
for visibility against the dark base; the lockscreen glow was hand-tuned
with extra noise dithering to avoid gradient banding — the generator script
used lives only in the session scratchpad, not in git history).
