All eight accent hues (yellow/orange/red/magenta/violet/blue/cyan/green) are
Ethan Schoonover's original, unmodified values from
[ethanschoonover.com/solarized](https://ethanschoonover.com/solarized/), and
are held **identical between Dark and Light** — this is the actual point of
Solarized's design: the accents were chosen via CIELAB so the same eight
hues read correctly against both the dark and light neutral ranges, unlike
Zephyr/Harmattan's `link` which is deliberately re-weighted per variant.

Only the eight `base03`–`base3` neutral tones swap roles between Dark and
Light (Dark uses base03→base01 for backgrounds and base0/base1 for text;
Light inverts this — see `../light/palette.md`). `bg-panel` and
`bg-header` are the two values with no official Solarized name — solarized
only defines two canonical background shades per mode, so these are
hand-interpolated midpoints (the one departure from pure Solarized values,
same spirit as Zephyr's interpolated `border`).

Kitty's ANSI colors 8–15 follow Solarized's actual, well-known terminal
mapping rather than invented "bright" hues: bright-black/white/green/
yellow/blue/cyan reuse the base0–base3 tones, and only bright-red
(orange) and bright-magenta (violet) get genuine second hues — this
mapping is original to Solarized itself, not something invented for this
scheme.

Desktop wallpaper (`~/.img/wallpapers/solarized_dark_desktop.png`, soft
overlapping translucent circles in the accent hues) and swaylock background
(`solarized_dark_lockscreen.png`, a subtle radial glow, bg → bg-panel-alt)
are both generated by `~/dotfiles/bin/palette_wallpaper.py --palette
solarized_dark` (desktop used `--pattern circles`, alpha boosted for
visibility against the dark base; the lockscreen glow was hand-tuned with
extra noise dithering to avoid gradient banding).
