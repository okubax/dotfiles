Mirror image of `../dark/palette.md`: the same eight accent hues, the same
neutral *tones*, just swapped roles (base3/base2 anchor the light
backgrounds here instead of base03/base02; base00/base1 carry body/muted
text here instead of base0/base01). See that file for the full rationale —
this is what Solarized's own design already prescribes, not an
interpretation. `bg-panel` and `bg-header` are the same two
hand-interpolated midpoints in spirit (base2→base1 and base1→base0), since
Solarized only ever defines two canonical background shades per mode.

Desktop wallpaper (`~/.img/wallpapers/solarized_light_desktop.png`, soft
overlapping translucent circles in the accent hues) and swaylock background
(`solarized_light_lockscreen.png`, a subtle radial glow, bg → bg-panel-alt)
are both generated by `~/dotfiles/bin/palette_wallpaper.py --palette
solarized_light` (desktop used `--pattern circles`; the lockscreen glow was
hand-tuned with extra noise dithering to avoid gradient banding).
