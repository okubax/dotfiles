# Daguerre — a full-tonal-range monochrome scheme for the sway desktop

An original scheme, built from scratch for this dotfiles repo. Daguerre is
named after the daguerreotype, an early black-and-white photographic
process, and is built around a single smooth ramp spanning the whole
0–255 range in even steps — loosely inspired by the photographic zone
system's eleven-stop black-to-white progression (not a reproduction of
it — the exact steps here are this port's own). Where Litho jumps in big
steps and Vellum stays inside a narrow band, Daguerre uses the full range
with fine, even gradation — a photographic tonal chart, not a poster or a
sketch. **Two variants only** — `dark` and `light` — no dusk equivalent.

## Where the colors come from

Every value is an original point on a strict grayscale ramp (R=G=B in
every hex value — no hue anywhere), spaced roughly evenly from `#000000`
to `#FFFFFF`. See `dark/palette.md` and `light/palette.md` for the full
swatch list and role mapping, including how `red`/`green`/`yellow`/
`purple` (semantic roles, not literal hues) and kitty's `cyan`/`orange`
slots resolve to gray steps when there's no hue to give them a distinct
identity.

## Wallpapers

Desktop wallpaper and swaylock's lock-screen background are generated by
`~/.cfg-tzevaot/bin/scheme_wallpaper.py`, the repo's one wallpaper
generator, built around each family's role-based palette. Daguerre's
desktop uses the `bands` pattern (a diagonal gradient across the full
bg->fg range, warped by a gentle ripple so the tonal steps read as soft
bands — the photographic-gradient feel); the lockscreen uses `glow` (a
radial vignette from `accent` to `bg`), the same pattern every family's
lockscreen uses. Regenerate with:

```
scheme_wallpaper.py --palette daguerre_dark  --pattern bands --output ~/.img/wallpapers/daguerre_dark_desktop.png
scheme_wallpaper.py --palette daguerre_dark  --pattern glow  --output ~/.img/wallpapers/daguerre_dark_lockscreen.png
scheme_wallpaper.py --palette daguerre_light --pattern bands --output ~/.img/wallpapers/daguerre_light_desktop.png
scheme_wallpaper.py --palette daguerre_light --pattern glow  --output ~/.img/wallpapers/daguerre_light_lockscreen.png
```

## Layout

```
daguerre/
  dark/    — one file per app, Daguerre Dark values, in that app's native syntax
  light/   — same, Daguerre Light values
  active -> dark | light   (symlink; this is what every app config points at)
```

Same wiring as every other family — `sway/config`, `mako/config`,
`waybar/style.css`, `wofi/style.css` each include/`@import`
`<theme>/active/...`; `swaylock` has no include mechanism so
`daguerre-theme` copies the variant's config over `swaywm/swaylock/config`
directly; vim picks its colorscheme independently, as an ordinary toggle
option (`vim/colors/daguerre_{dark,light}.vim`); kitty and mutt are
switched automatically along with everything else
(`kitty/colors/daguerre_{dark,light}.conf`,
`mutt/colors/daguerre_{dark,light}.muttrc` — approximated to the
nearest xterm 256-color, since mutt has no truecolor support).

Daguerre also ships a KDE Frameworks color scheme
(`{dark,light}/Daguerre{Dark,Light}.colors`) — once symlinked/copied into
`~/.local/share/color-schemes/`, `daguerre-theme` applies the matching one
automatically via `plasma-apply-colorscheme DaguerreDark`/`DaguerreLight` on
every switch, same as every other family's KDE schemes.

## Coexisting with other themes

Only one theme family drives sway/mako/waybar/wofi's chrome at a time —
whichever of `litho-theme`/`vellum-theme`/`daguerre-theme`/
`verdigris-theme` ran most recently. Each script rewrites the shared
`swaywm/<family>/active/...` include paths to point at itself, and
rewrites kitty's `include` and mutt's `source` line to match. vim is
unaffected — its variants sit side by side as an ordinary flat
colorscheme option.

## Switching

```
daguerre-theme dark    # switch everything (except vim) to Daguerre Dark
daguerre-theme light   # switch everything (except vim) to Daguerre Light
daguerre-theme toggle  # flip dark <-> light
daguerre-theme status  # show which variant is active
```

Reloads sway (`swaymsg reload`), mako (`makoctl reload`) and waybar
(`SIGUSR2`) itself; kitty picks up the new include on next launch, or press
ctrl+shift+F5 in an open kitty window to reload it live. For vim, run
`:colorscheme daguerre_dark` (or `_light`) in a running session, or change
the `colorscheme` line in `vimrc` if you want it to be the new default.
mutt picks up the new `source` line on next launch, or run
`:source ~/.config/mutt/muttrc` in an open session to reload it live.
