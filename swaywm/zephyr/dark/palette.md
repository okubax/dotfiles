Desktop wallpaper (`~/.img/wallpapers/zephyr_dark_desktop.png`, soft overlapping
translucent circles in the 6 accent hues, alpha boosted to 190/255 — the
generator's default 100/255 reads muddy against a near-black base) and swaylock
background (`zephyr_dark_lockscreen.png`, a subtle radial glow, surface1 → crust)
are both generated by `~/dotfiles/bin/catppuccin_wallpaper.py --palette
zephyr_dark` (desktop pattern was regenerated standalone for the higher alpha;
the lockscreen glow was hand-tuned with extra noise dithering to avoid gradient
banding — see git history for the exact script).
