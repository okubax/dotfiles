Every value here is upstream [Catppuccin](https://github.com/catppuccin)'s
own, unmodified Mocha flavor. **Unlike Zephyr/Harmattan/Solarized/Nord,
this theme's accents are *not* held constant across variants** — Mocha,
Macchiato and Latte each have genuinely different accent hues upstream
(compare `blue` here, `#89B4FA`, against Light's `#1E66F5`), not just
different neutrals. Staying faithful to what Catppuccin actually ships
matters more here than forcing this repo's usual cross-variant accent
discipline onto a palette that was never designed that way.

Catppuccin ships **four** official flavors (Latte, Frappé, Macchiato,
Mocha, lightest to darkest) but this integration only uses three, to fit
the Zephyr-style light/dusk/dark shape: `light` = Latte, `dusk` =
Macchiato, `dark` = Mocha. Frappé (the flavor between Latte and Macchiato)
isn't used here — it's still available standalone via
`~/dotfiles/bin/palette_wallpaper.py --palette frappe` for wallpaper
generation if wanted.

Desktop wallpaper (`~/.img/wallpapers/catppuccin_dark_desktop.png`, soft
overlapping translucent circles in the accent hues) and swaylock background
(`catppuccin_dark_lockscreen.png`, a subtle radial glow, base → surface1)
are both generated by `~/dotfiles/bin/palette_wallpaper.py --palette
mocha` (desktop used `--pattern circles`, alpha boosted for visibility
against the dark base; the lockscreen glow was hand-tuned with extra noise
dithering to avoid gradient banding).
