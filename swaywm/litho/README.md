# Litho — a stark, high-contrast monochrome scheme for the sway desktop

An original scheme, built from scratch for this dotfiles repo — not a port
of anything. Litho is one of three new monochrome families added alongside
Zephyr/Harmattan/Solarized/Nord/Catppuccin, and the one built around bold
contrast: a small set of flat gray "plates" with big jumps between them,
and the two pure extremes (`#000000`/`#FFFFFF`) reserved for `bg`/`fg`/
`accent`. Think ink on a lithograph plate — few tones, high contrast, no
gradient. **Two variants only** — `dark` and `light` — there's no dusk
equivalent, same as Solarized.

## Where the colors come from

Every value is an original, hand-picked point on a strict grayscale ramp
(R=G=B in every hex value — no hue anywhere). See `dark/palette.md` and
`light/palette.md` for the full swatch list and the exact role mapping,
including how `red`/`green`/`yellow`/`purple` (semantic roles, not literal
hues) and kitty's `cyan`/`orange` slots resolve to gray steps when there's
no hue to give them a distinct identity.

`accent` sits at the same value as `fg` in both variants — in Litho there's
no daylight between "text" and "emphasis"; focus/selection is carried by
full inversion (swapping fg/bg) rather than a separate color.

## Wallpapers

Desktop wallpaper and swaylock's lock-screen background are generated by
`~/.cfg-tzevaot/bin/scheme_wallpaper.py` — a standalone generator built for
these three monochrome schemes' role-based palettes (`bg`/`fg`/`accent`/...,
the same roles `palette.md` already documents), independent of
`palette_wallpaper.py` which the other five families use. Litho's desktop
uses the `dots` pattern (a brick-offset grid of circles sized by a soft
sine field — the poster/halftone feel); the lockscreen uses `glow` (a
radial vignette from `accent` to `bg`), the same pattern every family's
lockscreen uses. Regenerate with:

```
scheme_wallpaper.py --palette litho_dark  --pattern dots --seed 7 --output ~/.img/wallpapers/litho_dark_desktop.png
scheme_wallpaper.py --palette litho_dark  --pattern glow --output ~/.img/wallpapers/litho_dark_lockscreen.png
scheme_wallpaper.py --palette litho_light --pattern dots --seed 7 --output ~/.img/wallpapers/litho_light_desktop.png
scheme_wallpaper.py --palette litho_light --pattern glow --output ~/.img/wallpapers/litho_light_lockscreen.png
```

## Layout

```
litho/
  dark/    — one file per app, Litho Dark values, in that app's native syntax
  light/   — same, Litho Light values
  active -> dark | light   (symlink; this is what every app config points at)
```

Same wiring as every other family — `sway/config`, `mako/config`,
`waybar/style.css`, `wofi/style.css` each include/`@import`
`<theme>/active/...`; `swaylock` has no include mechanism so `litho-theme`
copies the variant's config over `swaywm/swaylock/config` directly; kitty
and vim pick their colorscheme independently as ordinary toggle options
(`kitty/colors/litho_{dark,light}.conf`, `vim/colors/litho_{dark,light}.vim`).

Litho also ships a KDE Frameworks color scheme
(`{dark,light}/Litho{Dark,Light}.colors`) — **deliberately not wired into
`litho-theme`**, same as every other family's KDE schemes. Apply one with
`plasma-apply-colorscheme LithoDark` (or `LithoLight`) after symlinking/
copying the `.colors` file into `~/.local/share/color-schemes/`.

## Coexisting with other themes

Only one theme family drives sway/mako/waybar/wofi's chrome at a time —
whichever of `zephyr-theme`/`harmattan-theme`/`solarized-theme`/
`nord-theme`/`catppuccin-theme`/`litho-theme`/`vellum-theme`/
`daguerre-theme` ran most recently. Each script rewrites the shared
`swaywm/<family>/active/...` include paths to point at itself. kitty and
vim are unaffected — every theme's variants sit side by side as ordinary
flat toggle/colorscheme options.

## Switching

```
litho-theme dark    # switch everything (except vim) to Litho Dark
litho-theme light   # switch everything (except vim) to Litho Light
litho-theme toggle  # flip dark <-> light
litho-theme status  # show which variant is active
```

Reloads sway (`swaymsg reload`), mako (`makoctl reload`) and waybar
(`SIGUSR2`) itself; kitty picks up the new include on next launch, or press
ctrl+shift+F5 in an open kitty window to reload it live. For vim, run
`:colorscheme litho_dark` (or `_light`) in a running session, or change the
`colorscheme` line in `vimrc` if you want it to be the new default.
