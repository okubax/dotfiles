# Vellum — a soft, muted monochrome scheme for the sway desktop

An original scheme, built from scratch for this dotfiles repo. Vellum is
the softest of the three new monochrome families: a narrow, compressed
gray range that never touches pure black or pure white — even `accent`,
the boldest tone available, is still an off-white (dark variant) or
off-black (light variant), not an extreme. Graphite on paper, not ink on
a plate — that contrast with Litho's stark extremes is the whole point.
**Two variants only** — `dark` and `light` — no dusk equivalent.

## Where the colors come from

Every value is an original, hand-picked point on a strict grayscale ramp
(R=G=B in every hex value — no hue anywhere), deliberately kept within a
narrow band (roughly 46–230 out of 0–255 in the dark variant) so nothing
ever reaches a harsh extreme. See `dark/palette.md` and `light/palette.md`
for the full swatch list and role mapping, including how `red`/`green`/
`yellow`/`purple` (semantic roles, not literal hues) and kitty's `cyan`/
`orange` slots resolve to gray steps when there's no hue to give them a
distinct identity.

## Wallpapers

Desktop wallpaper and swaylock's lock-screen background are generated by
`~/.cfg-tzevaot/bin/scheme_wallpaper.py` — a standalone generator built for
these three monochrome schemes' role-based palettes, independent of
`palette_wallpaper.py` which the other five families use. Vellum's desktop
uses the `grain` pattern (blurred random noise remapped into a narrow
bg->bg_header slice — a soft mottled paper/graphite texture); the
lockscreen uses `glow` (a radial vignette from `accent` to `bg`), the same
pattern every family's lockscreen uses. Regenerate with:

```
scheme_wallpaper.py --palette vellum_dark  --pattern grain --seed 3 --output ~/.img/wallpapers/vellum_dark_desktop.png
scheme_wallpaper.py --palette vellum_dark  --pattern glow  --output ~/.img/wallpapers/vellum_dark_lockscreen.png
scheme_wallpaper.py --palette vellum_light --pattern grain --seed 3 --output ~/.img/wallpapers/vellum_light_desktop.png
scheme_wallpaper.py --palette vellum_light --pattern glow  --output ~/.img/wallpapers/vellum_light_lockscreen.png
```

## Layout

```
vellum/
  dark/    — one file per app, Vellum Dark values, in that app's native syntax
  light/   — same, Vellum Light values
  active -> dark | light   (symlink; this is what every app config points at)
```

Same wiring as every other family — `sway/config`, `mako/config`,
`waybar/style.css`, `wofi/style.css` each include/`@import`
`<theme>/active/...`; `swaylock` has no include mechanism so `vellum-theme`
copies the variant's config over `swaywm/swaylock/config` directly; kitty
and vim pick their colorscheme independently as ordinary toggle options
(`kitty/colors/vellum_{dark,light}.conf`, `vim/colors/vellum_{dark,light}.vim`).

Vellum also ships a KDE Frameworks color scheme
(`{dark,light}/Vellum{Dark,Light}.colors`) — **deliberately not wired into
`vellum-theme`**, same as every other family's KDE schemes. Apply one with
`plasma-apply-colorscheme VellumDark` (or `VellumLight`) after symlinking/
copying the `.colors` file into `~/.local/share/color-schemes/`.

## Coexisting with other themes

Only one theme family drives sway/mako/waybar/wofi's chrome at a time —
whichever of `zephyr-theme`/`harmattan-theme`/`solarized-theme`/
`nord-theme`/`catppuccin-theme`/`litho-theme`/`vellum-theme`/
`daguerre-theme` ran most recently. Each script rewrites the shared
`swaywm/<family>/active/...` include paths to point at itself. kitty and
vim are unaffected — every theme's variants sit side by side as ordinary
flat toggle/colorscheme options.

## Switching

```
vellum-theme dark    # switch everything (except vim) to Vellum Dark
vellum-theme light   # switch everything (except vim) to Vellum Light
vellum-theme toggle  # flip dark <-> light
vellum-theme status  # show which variant is active
```

Reloads sway (`swaymsg reload`), mako (`makoctl reload`) and waybar
(`SIGUSR2`) itself; kitty picks up the new include on next launch, or press
ctrl+shift+F5 in an open kitty window to reload it live. For vim, run
`:colorscheme vellum_dark` (or `_light`) in a running session, or change
the `colorscheme` line in `vimrc` if you want it to be the new default.
